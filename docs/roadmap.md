# Roadmap

These items are not claims of implemented features.

1. Independent ECU simulator integration tests, captured protocol fixtures, and sustained dashboard/heap testing.
2. Reviewed automotive power/CAN front end, PCB schematic/layout, enclosure and EMC/transient validation.
3. Explicit 29-bit addressing support with tests; safe per-vehicle configuration profiles.
4. Readiness details, freeze-frame and pending/permanent DTC reads; VIN only with privacy controls.
5. Local timestamped recording and CSV export with deliberate user action and data-retention controls.
6. Ignition-aware sleep, low standby current, and measured battery-drain behavior.
7. Trend summaries that describe evidence and uncertainty without inventing a universal “health score.”

ECU writes, actuator control and fault clearing are outside this prototype's current safety scope.
